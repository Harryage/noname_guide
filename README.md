## ✅ 每篇指南的写作原则

为了保持质量，每篇文档尽量遵循：

1. **写清楚适用场景**——什么情况下该用这个方法，什么情况下不该用
2. **保留踩坑记录**——不隐藏走过的弯路，报错信息原样贴出来，方便别人用报错信息搜索定位
3. **区分"正确路径"和"排错手册"**——正文给最短可行路径，常见问题单独成节
4. **给出验证方式**——怎么确认每一步是成功的，而不是走完流程才发现哪步错了
